# SkillOS 容量规划文档

> **适用范围**: SkillOS v0.6.0-beta | **更新日期**: 2026-07-30
> **参考**: [docs/capacity.md](./capacity.md) (详细基线数据)

## 1. 关键边界

| 指标 | 上限 | 触发条件 | 后果 |
|------|------|---------|------|
| **SQLite 存储** | 10 GB | 日志 + 审计数据增长 | 写入性能退化，超出后建议迁移 PostgreSQL |
| **单进程 QPS** | 200 QPS | HTTP API + SSE 连接 | 超过后响应 P99 退化至 > 1s |
| **并发 WebSocket** | 500 连接 | Agent 流式输出 | 文件描述符耗尽 |
| **审计日志行数** | 10M 行 | 日活 > 5K Agent | 查询性能退化 (无索引) |
| **技能注册数** | 10K skills | 社区贡献增长 | Registry 启动加载时间 > 10s |

## 2. 扩容触发条件

| 指标 | 黄色预警 | 红色预警 | 操作 |
|------|---------|---------|------|
| CPU 使用率 | > 60% | > 80% | 垂直扩容 / 增加副本 |
| 内存使用率 | > 70% | > 85% | 检查内存泄漏 / 增加副本 |
| 磁盘使用率 | > 75% | > 90% | 清理旧审计日志 / 迁移 PostgreSQL |
| P99 响应时间 | > 300ms | > 500ms | 增加副本 / 优化热点 |
| QPS | > 150 | > 200 | 水平扩展 (需 Redis + PostgreSQL) |

## 3. 容量估算模型

```
单节点容量 = min(CPU·200 QPS, 磁盘·10 GB, 内存·500 sessions)
多节点容量 = N * 单节点 * 0.85 (15% 共识开销)
```

当前估算适用场景:
- **Dev**: 单节点, 10~50 QPS, SQLite
- **Staging**: 单节点, 50~100 QPS, PostgreSQL
- **Production**: 2+ 节点, 200~400 QPS, PostgreSQL + Redis

## 4. 存储增长预测

| 数据源 | 月增长 | 年增长 | 清理策略 |
|--------|--------|--------|---------|
| 审计日志 | 500 MB | 6 GB | 90 天轮转 (保留 30 天在线) |
| 技能注册 | 50 MB | 600 MB | 无主动清理 |
| 结算记录 | 100 MB | 1.2 GB | 归档 1 年以上到冷存储 |
| 反模式样本 | 200 MB | 2.4 GB | 按风险等级保留 6 个月 |
