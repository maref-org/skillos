# SkillOS 单点故障 (SPOF) 分析与 HA 路线图

> **适用范围**: SkillOS v0.6.0-beta | **更新日期**: 2026-07-30
> **上位法**: [全栈PRR审计报告](../全栈PRR审计报告_2026-07-03.md)

## 1. 当前 SPOF 清单

| 层级 | 组件 | 风险等级 | 说明 |
|------|------|---------|------|
| **进程** | 单进程 Web 服务 (Uvicorn) | **高** | 无多副本/负载均衡，进程崩溃即全量不可用 |
| **数据库** | SQLite 单文件 | **高** | 无主从/无故障转移，文件损坏即数据丢失 |
| **存储** | 本地磁盘审计日志 | **中** | 日志写本地，实例销毁即丢失 |
| **密钥** | `SKILLOS_AUDIT_SECRET` 单 Key | **中** | 无 Key 轮换机制，泄露需手动更换 |
| **调度** | `AgentScheduler` 单进程 | **高** | 调度器故障 → 所有定时任务中断 |
| **网络** | 单出口公网 IP | **低** | 仅影响对外 API 回调场景 |

## 2. 消除路线图

| 阶段 | 目标 | 措施 | 目标版本 |
|------|------|------|---------|
| **Phase B** (当前) | 数据库 HA | PostgreSQL 支持 (主从/故障转移) | v0.6.0 |
| **Phase B** (当前) | 进程冗余 | Docker Compose 多副本 + 健康检查 | v0.6.0 |
| **v0.7.0** | 无状态化 | 会话外置到 Redis，支持水平扩缩 | v0.7.0 |
| **v0.7.0** | 密钥轮换 | Vault/KMS 集成 + 自动轮换 | v0.7.0 |
| **v0.8.0** | 多 AZ | 跨可用区部署 + DNS 故障转移 | v0.8.0 |

## 3. 架构限制说明

- **Session 状态**: 当前进程内存存储，重启丢失 → v0.7.0 迁移到 Redis
- **调度器锁**: `AgentScheduler` 无分布式锁 → 多实例会重复触发
- **审计日志**: 本地文件轮转，无远程复制 → 当前接受"最多丢失 1 天"的 RPO

## 4. HA 验收标准 (v0.6.0)

- [ ] PostgreSQL 故障切换: 主库宕机 → 从库升主 ≤ 30s
- [ ] 进程健康检查: `GET /health` → 200
- [ ] 重启恢复: 进程 kill → systemd 自动拉起 ≤ 10s
