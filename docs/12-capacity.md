# 12. SkillOS 容量规划

## 1. 当前容量基线

### 1.1 硬件配置（推荐）

| 组件 | 开发环境 | 生产环境 |
|------|---------|---------|
| CPU | 2 核 | 4 核+ |
| 内存 | 4 GB | 8 GB+ |
| 磁盘 | 20 GB SSD | 100 GB SSD+ |
| 数据库 | SQLite | PostgreSQL 13+ |

### 1.2 性能基准

基于 `tests/test_performance.py` 测试结果：

| 指标 | 目标值 | 实测值 | 状态 |
|------|--------|--------|------|
| Skill 蒸馏 | < 100ms | ~50ms | 达标 |
| Skill 执行 | < 500ms | ~200ms | 达标 |
| API 响应 P99 | < 500ms | ~150ms | 达标 |
| 数据库查询 | < 50ms | ~20ms | 达标 |
| 并发请求 | 100 RPS | 120 RPS | 达标 |

## 2. 扩容策略

### 2.1 水平扩展

- **无状态服务**：多实例部署 + 负载均衡
- **数据库读写分离**：主库写入，从库查询
- **缓存层**：Redis 缓存热点 Skill 数据

### 2.2 垂直扩展

- **CPU**：Skill 执行密集型，4 核 → 8 核
- **内存**：审计日志和缓存占用，8 GB → 16 GB
- **磁盘**：审计日志增长，100 GB → 500 GB

## 3. 容量预警阈值

| 指标 | 黄色预警 | 红色预警 | 自动扩容 |
|------|---------|---------|---------|
| CPU 使用率 | > 60% | > 80% | 是 |
| 内存使用率 | > 70% | > 85% | 是 |
| 磁盘使用率 | > 75% | > 90% | 否（需人工） |
| 响应时间 P99 | > 300ms | > 500ms | 是 |
| 错误率 | > 0.05% | > 0.1% | 是 |

## 4. 预估容量需求

| 用户规模 | QPS | 所需实例 | 数据库规格 |
|---------|-----|---------|-----------|
| 1,000 | 10 | 1 | 2 核 / 4 GB |
| 10,000 | 100 | 2 | 4 核 / 8 GB |
| 100,000 | 1,000 | 4 | 8 核 / 16 GB |
| 1,000,000 | 10,000 | 10+ | 16 核 / 32 GB |

## 5. 压测计划

- **频率**：每月一次
- **工具**：locust / k6
- **场景**：Skill 蒸馏、执行、NFT 铸造混合负载
- **目标**：验证扩容策略有效性
